# Group-Project-Repository
Firmware and interface for a prototype mesh sensor network using Raspberry Pi Zero and Particle Photon devices. Built for experimentation and demonstration of networking technologies including LoRa, S2C/serial inputs, packet transmission and reception, and microcontroller-based distributed systems.

# Making Changes
To those unfamilar with GitHub. To make changes, please create a new feature branch ( called "feature/[name]" ). Once the feature is complete, create a pull request (a message saying that a feature needs reviewed). Set base to 'develop' and compare to 'feature/[name]'. From there the admin will merge INTO develop.
